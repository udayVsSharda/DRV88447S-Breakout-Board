# DRV88447S-Breakout-Board
A DRV8847 Break out Board for driving Stepper Motors, Brushed DC Motors and Solenoids. The motor supply voltage can be between 2.7V to 18V. Digital control signals at 3.3V,  allows indirect control through I2C or direct control through 4 GPIO inputs to the Dual H-bridges.Also included are manufactoring files for JLCPCB.
